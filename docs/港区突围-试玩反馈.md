# 《港区突围》试玩反馈清单

## 你的试玩反馈

在对应分类下直接写，一条感受一行。有明确预期时，可以写成「什么时候发生 → 我感觉怎样 → 我希望怎样」。只填有意见的分类即可。最影响试玩的一条可以标上「优先」。

### 开场与路线

从码头退回安全屋的运镜、开场节奏、出门方向、能否辨认终点。

- 

### 移动与视角

WASD、转向灵敏度、视野、跳跃、街边碰撞或卡住的位置。

- 

### 枪械与射击手感

G18、AK、霰弹枪的差异，开火反馈、右键瞄准、换弹、切枪。

- 

### 僵尸与受击效果

尸群分布、追击与围堵、命中部位、体素破坏、断肢与死亡反馈。

- 

### 关卡、难度与重试

哪一段最紧张或最空，能否绕过尸群，阵亡后是否想再冲一趟，抵达码头时的体验。

- 

### 赏金与成长

击杀到账、买到第一把新枪的时机、价格、弹药量、下一趟保留的进度。

- 

### 场景、美术与声音

安全屋、街道与码头的辨识度，末世氛围，枪声、脚步或尸群声。

- 

### 界面与操作提示

准星、生命、弹药、现金、买枪提示、距离和结算画面是否看得清、看得懂。

- 

### 性能、故障及其他

卡顿、输入失灵、刷新后异常，或前面放不下的想法。故障若能重复，可顺手写下触发动作。

- 

## 逐条优化与验收

你填完后，我给每条反馈分配固定编号，保留原话，补上可在试玩中判断的验收条件。每条单独记录改动、实际检查方式和结果。需要复测的条目沿用原编号。

| 编号 | 分类及反馈原文 | 验收条件 | 实际改动 | 我的检验方式与结果 | 处理状态 | 你的验收结论及意见 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

处理状态依次使用「待处理」「已修改，待检验」「待你验收」。检验未通过时记录「返工」；受环境影响时记录「检验受阻」及原因。手感类反馈会写出试玩入口和复现动作，方便你亲自判断。

最后一栏由你填写，也可以在聊天里按编号回复「通过」或「需调整」并说明感受。你确认通过后，该条记为「已验收」。
