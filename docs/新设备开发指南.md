# 《港区突围》新设备开发指南

在新设备上打开 Codex，选择一个用于存放游戏的目录，将下面的指令复制给它。项目地址为 [StarSpawn/KillZombiesGame](https://github.com/StarSpawn/KillZombiesGame)，开发分支为 `main`。

## 首次安装和预览

> 请在这台设备上恢复《港区突围》的开发环境，并实际启动游戏。
>
> 1. 如果项目尚未下载，请运行 `git clone https://github.com/StarSpawn/KillZombiesGame.git` 并进入项目目录。如果已有项目，请先检查当前分支和本地修改，保留已有工作，再同步远端进度。
> 2. 阅读项目根目录的 `AGENTS.md`、`README.md` 和依赖配置。检查 Node.js 是否兼容，准备项目指定的 pnpm（当前为 `12.15.0`），在项目根目录运行 `pnpm install --frozen-lockfile`。
> 3. 当前项目使用 `@forgeax/engine@0.5.0`。如果安装失败，请查明缺少的 SDK、离线包或访问权限，并告诉我具体需要提供什么。保留项目锁定的依赖版本。
> 4. 本次允许使用 ForgeaX 本地 CLI 构建和预览游戏。请运行 `pnpm exec tsc --noEmit`，然后按 README 构建并启动本地预览。确认页面能打开后，把预览地址发给我。无需录屏或发布。
> 5. 后续每项有文件改动的任务完成后，按项目约定验证、提交并推送，核对远端提交。

## 日常切换设备

离开当前设备前，确认本次任务的提交已推送。回到已安装过项目的设备时，打开原来的项目目录，把下面这句话发给 Codex 即可。

> 先检查当前分支和本地修改，保留已有工作，再同步 GitHub 上的最新进度。如果依赖锁文件有更新，请按锁文件安装依赖，然后继续今天的任务。
